# Rainbow-KRAKEN

This repository contains the simulation and analysis pipeline for the Rainbow-KRAKEN project. It comprises various scripts intended for generating simulated signals, processing experimental data, reconstructing probe spectra, and performing Bayesian estimation of density matrix parameters.

## Repository Structure

### Main Execution Scripts
- **`RK_MAIN.py`**: The main script for running simulated experiments. It initializes and runs the experiment class defined in `RK_experiment.py`.
- **`RK_MAIN_EXP.py`**: The counterpart to `RK_MAIN.py` designed specifically for handling real experimental data. It works in conjunction with `RK_experiment_EXP.py`, containing slight adjustments compared to the simulation pipeline.
- **`RK_MAIN_iterate.py`**: Implements an iterative algorithm for simultaneous probe spectrum and density matrix retrieval. It relies on the classes defined in `RK_experiment.py`.
- **`RK_MAIN_double.py`**: Implements the two-scan protocol using `RK_experiment.py`.

### Experiment Definitions
- **`RK_experiment.py`**: Defines the core experiment class used by the simulation scripts.
- **`RK_experiment_EXP.py`**: Defines the modified experiment class to handle the formatting and nuances of real experimental data.

### Core Algorithms & Utilities
- **`rkraken.py`**: Contains general-purpose utility functions used throughout the project for both simulation and experimental data processing.
- **`LBFGSprobe.py`**: Implements an optimization algorithm for the reconstruction of the probe spectrum from the measurement signals.
- **`MCMCrho.py`**: Uses a Markov Chain Monte Carlo (MCMC) Bayesian estimation method to infer density matrix parameters based on the reconstructed data.

### Plotting and Output
- **`PLOTTING.py`**: Handles the visualization of the results and plots the output in the `plot_output/` folder.
- **`single_output_temp/`**: A directory where the raw and processed output arrays (e.g., `.npz` files) from the various `RK` scripts are temporarily stored through the different steps of the pipeline.
- **`plot_output/`**: Directory where final visualizations and plots generated by `PLOTTING.py` are saved.
